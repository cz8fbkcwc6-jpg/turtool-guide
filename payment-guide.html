터TOOL 수납 메뉴 사용 방법
PRO

월세 수납을 자동으로
처리해드립니다

입주민이 입금하면 터TOOL이 감지해 즉시 수납을 완료합니다. 직접 확인하고 기록할 필요가 없어요.

입금 감지 후 자동 완납 처리
입금자명으로 입주민 자동 매칭
다음 달 수납 스케줄 자동 생성
미납 시 지정일에 독촉 알림 자동 발송
자동 수납 전 필요한 설정 순서
수납 계좌 등록 → 알림번호 등록 → 입주민 송금자명 등록
이 순서대로 설정해야 자동 수납이 정상 작동합니다.
수납 화면 구성
월별 수납 현황 카드
이번 달 완납·미납·부분납 인원을 한눈에 확인할 수 있습니다. 좌우로 스와이프하면 다른 달을 조회할 수 있어요.
미확인 입금 카드
입금자명이 등록된 송금자명과 다를 경우 여기에 표시됩니다. 입주민과 직접 연결하거나 삭제할 수 있어요.
입주민 목록
전체·미납·완납·부분납 필터로 납부 상태를 빠르게 확인하고 개별 처리를 할 수 있습니다.
자동 수납 전체 흐름
1
수납 계좌 등록
수납 설정에서 월세 받을 계좌의 은행명, 계좌번호, 예금주를 등록합니다.
2
알림번호 등록 1회 설정
터TOOL 알림번호를 은행 앱의 입금 알림번호로 등록합니다. 은행별 설정 방법은 알림번호 설정 가이드를 참고하세요.
3
입주민 송금자명 등록
각 입주민이 입금할 때 사용하는 이름을 터TOOL에 등록합니다. 은행에 표시되는 이름과 정확히 일치해야 자동으로 누구의 수납인지 식별합니다.
4
입주민 입금 감지 자동
입주민이 계좌로 입금하면 터TOOL이 실시간으로 감지합니다.
5
자동 완납 처리 자동
등록된 송금자명과 입금자명이 일치하면 즉시 완납으로 처리되고 원장님 앱으로 알림이 발송됩니다.
입금자명으로 입주민을 식별합니다
입금 시 표시되는 이름과 터TOOL에 등록된 송금자명이 일치해야 해당 입주민의 수납으로 자동 처리됩니다. 이름이 다르면 미확인 입금으로 분류됩니다.
등록 방법
1
수납 탭 하단 입주민 목록에서 선택
송금자명을 등록할 입주민 행을 탭합니다.
2
송금자명 입력
입주민이 입금할 때 실제로 사용하는 이름을 입력합니다. 은행 계좌에 표시되는 이름과 정확히 일치해야 합니다.
3
저장
저장 후 해당 이름으로 입금이 들어오면 자동으로 이 입주민의 완납으로 처리됩니다.
동명이인이 있다면
같은 이름의 입주민이 여러 명이라면 송금자명을 다르게 설정하도록 안내해주세요.
예) 홍길동이 두 명 → 홍길동101, 홍길동202처럼 구분
미확인 입금이 생기는 경우
입금자명이 다를 때
입주민이 다른 이름으로 입금하거나 송금자명이 미등록된 경우 미확인 입금으로 분류됩니다.
테스트 입금을 했을 때
알림번호 등록 테스트 시 보낸 소액 입금이 미확인 입금으로 표시될 수 있습니다. 삭제하면 됩니다.
처리 방법
1
수납 화면의 미확인 입금 카드 탭
카드를 탭하면 해당 입금 내역과 처리 옵션이 표시됩니다.
2
연결 또는 삭제 선택
입주민과 연결하기를 선택하면 어떤 입주민의 수납으로 처리할지 지정할 수 있습니다. 관련 없는 입금이라면 삭제하기로 제거합니다.
완납 처리
1
입주민 목록에서 해당 입주민 탭
수납 화면 하단 목록에서 처리할 입주민을 선택합니다.
2
완납 처리 버튼 탭
상세 화면에서 완납 처리 버튼을 탭하면 완납 날짜가 자동으로 기록됩니다.
부분납 처리
1
입주민 상세 화면에서 부분납 처리 탭
입주민 상세 화면의 부분납 처리 버튼을 탭합니다.
2
받은 금액 입력 후 저장
실제로 받은 금액을 입력하면 나머지 미납 금액이 자동으로 계산됩니다.
잘못 처리했다면
입주민 상세 화면에서 수납 취소를 통해 이전 상태로 되돌릴 수 있습니다.
자동 독촉 알림
발송 시점 설정
수납 설정에서 납부일 이후 며칠째에 독촉 알림을 보낼지 지정할 수 있습니다. 설정한 날에 미납 입주민에게 자동 발송됩니다.
알림 내용
입주민 앱으로 미납 알림이 발송됩니다. 미납 경과 일수와 납부 금액이 함께 표시됩니다.
수동 독촉 알림
1
미납 입주민 상세 화면으로 이동
수납 화면 하단 목록에서 미납 입주민을 탭합니다.
2
독촉 알림 즉시 전송
상세 화면에서 독촉 알림 버튼을 탭하면 즉시 해당 입주민 앱으로 알림이 발송됩니다.
방 변경 시 월세 차액을 자동 계산합니다
터 관리 메뉴에서 입주민의 방을 변경하면 이전 방과 새 방의 월세 차이를 기준으로 당월 일할 차액이 자동으로 계산됩니다.
계산 예시
월 중간 방 이동 시나리오
15일에 400,000원 → 500,000원 방으로 이동한 경우
이전 방 월세400,000원
새 방 월세500,000원
변경일15일
이번 달 추가 납부+16,667원
수납 화면에 자동 반영
방 변경 후 해당 입주민의 수납 화면에 차액 항목이 자동으로 추가됩니다.
입주민 앱에도 안내
입주민 앱에도 방 변경으로 인한 추가 납부 안내가 표시됩니다.

상세 화면에서 완납 처리 버튼을 탭합니다. 완납 날짜가 자동으로 기록됩니다.

1
입주민 상세 화면에서 부분납 처리 탭

1
미납 입주민 상세 화면으로 이동

독촉 알림 즉시 전송
상세 화면에서 독촉 알림 버튼을 탭하면 즉시 해당 입주민 앱으로 미납 알림이 발송됩니다.

자동 독촉은 프로 전용
지정일에 자동 발송되는 독촉 알림은 프로 플랜에서만 사용할 수 있습니다.
자동 독촉 알림 사용하기 프로 플랜으로 업그레이드하면 자동으로 발송됩니다
